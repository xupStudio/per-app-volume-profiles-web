設定與常見問題

Q1. App 音量沒有改變，先檢查什麼？

請確認三件事：(1) App Volume 目前有啟用的情境模式；(2) 該模式或全域規則中有這個 App；(3)「捷徑」App 的個人自動化已勾選這個 App，執行 Per-App Volume，並設為「立即執行」。可到 App Volume → 設定 → 逐步教學重新檢查。

Q2. 每個 App 都要建立一條個人自動化嗎？

不用。App Volume 需要 iOS / iPadOS 18.2 以上版本；安裝 Per-App Volume 範本一次，再建立一條 App 個人自動化，於「選擇」中勾選目前要控制的所有 App。日後新增規則時，只要把新 App 加進同一個觸發選擇器。

Q3. 為什麼 App Volume 不能替我建立個人自動化？

Apple 沒有提供第三方 App 建立或修改「捷徑」個人自動化的 API，因此最後的選擇 App、執行範本與「立即執行」必須由你在「捷徑」App 中完成。

Q4. 切換情境模式後，要重做自動化嗎？

不用。原本那條自動化會讀取目前啟用的情境模式。只有新增一個從未勾選過的 App 時，才需要把它加入原本自動化的 App 觸發條件。

Q5. 背景播放為什麼和預期不同？

iOS 只有一個全域媒體音量，自動化則在 App 進入前景時觸發。如果音樂留在背景播放，之後打開另一個有規則的 App，後者會改變同一個系統音量。iOS 不允許 App Volume 分別控制兩個同時播放的音訊串流。

Q6. 如何設定藍牙耳機獨立音量？

請先到 App Volume → 設定 → 教學 → 逐步設定教學，或從情境模式／全域規則的耳機音量區段打開設定流程：(1) 安裝 Connect 與 Disconnect 兩個 helper 捷徑；(2) 各建立一條藍牙個人自動化並選擇你的耳機；(3) 在情境模式中開啟耳機獨立音量，替需要的 App 調整音量；(4) 確認那些 App 也已勾進原本的 App 自動化。

Q7. 有線耳機可以使用嗎？

不支援。目前耳機狀態流程依賴 Apple「捷徑」提供的藍牙連線與中斷觸發；有線耳機沒有對應的個人自動化觸發。

Q8. iCloud 備份不是即時同步嗎？

不是。App Volume 提供手動備份、還原與可選的自動備份，資料存放在你自己的 CloudKit 私人資料庫。它不會即時合併多台裝置上的修改；請先在來源裝置完成備份，再於另一台裝置手動還原。

Q9. 目前需要付費嗎？

目前 App Store 上的版本完全免費，沒有訂閱。

Setup & Frequently Asked Questions

Q1. The volume did not change. What should I check?

Confirm three things: (1) a Mode is active in App Volume; (2) that Mode or Global Rules contains the app; and (3) your Shortcuts Personal Automation includes the app, runs Per-App Volume, and is set to Run Immediately. You can repeat the checklist in App Volume → Settings → Step-by-step setup.

Q2. Do I need a Personal Automation for every app?

No. App Volume requires iOS / iPadOS 18.2 or later. Install the Per-App Volume template once, then create one App Personal Automation and select every app you currently control. When you add a rule later, add the new app to that same trigger picker.

Q3. Why can't App Volume create the Personal Automation for me?

Apple provides no API for third-party apps to create or edit Shortcuts Personal Automations. You must complete the final app selection, shortcut action, and Run Immediately setting inside the Shortcuts app.

Q4. Do I need to rebuild the automation after switching Modes?

No. The existing automation reads the currently active Mode. You only need to edit it when adding an app that has never been selected in its App trigger.

Q5. Why does background playback behave differently?

iOS has one global media volume, and the automation runs when an app enters the foreground. If music keeps playing in the background and you open another app with a rule, that app changes the same system volume. iOS does not let App Volume control two simultaneous audio streams independently.

Q6. How do I set up separate Bluetooth headphone volume?

Start in App Volume → Settings → Tutorials → Step-by-step setup, or open the setup flow from the headphone-volume section of a Mode or Global Rules: (1) install the Connect and Disconnect helper shortcuts; (2) create one Bluetooth Personal Automation for each and choose your headphones; (3) enable separate headphone volume in a Mode and adjust the apps you need; and (4) make sure those apps are also selected in your existing App automation.

Q7. Are wired headphones supported?

No. The current headphone-state setup depends on Apple's Shortcuts Bluetooth connect and disconnect triggers. Shortcuts does not offer the corresponding Personal Automation trigger for wired headphones.

Q8. Is iCloud backup live sync?

No. App Volume offers manual backup, restore, and optional automatic backup in your private CloudKit database. It does not merge edits across devices in real time. Back up on the source device, then restore manually on the other device.

Q9. Does the current version require payment?

No. The current App Store version is free to use and has no subscription.
